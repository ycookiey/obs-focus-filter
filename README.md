# OBS Focus Filter

ウィンドウキャプチャに追加するだけで、**そのウィンドウを実際に見ている（フォーカスしている）間だけ**映像を OBS に映す単機能フィルタプラグイン。

Advanced Scene Switcher のような汎用自動化ツールではなく、この 1 機能のみを提供する。

## 機能

- ウィンドウキャプチャ / ゲームキャプチャ（ウィンドウ指定モード）のソースにフィルタ「フォーカス中のみ表示」を追加すると、キャプチャ対象ウィンドウがフォアグラウンドの間だけ描画される
- 非フォーカス時は完全に透明（背後のソースが見える）。フェードイン/アウトも設定可能
- 対象ウィンドウはフィルタ側で設定不要。親ソースのウィンドウ設定を OBS 本体と同じロジック（`ms_find_window`）で自動解決する

## 設定

| 項目 | 値 | 動作 |
|---|---|---|
| 表示する条件 | キャプチャ対象のウィンドウがフォーカス中（既定） | 対象ウィンドウ本体か、その所有ダイアログがフォアグラウンドの時のみ表示 |
| | 同じアプリのウィンドウがフォーカス中 | 同一プロセスのウィンドウであれば表示（複数ウィンドウのアプリ向け） |
| フェード時間 | 0〜2000 ms（既定 0） | 表示/非表示の切替時にフェードイン/アウト。0 で即時カット |

## 動作仕様

- フォアグラウンド判定は 100ms 周期のポーリング
- ウィンドウ指定を持たない親ソース（画面キャプチャ、フルスクリーンモードのゲームキャプチャ等）に付けた場合は何もしない（常に表示）
- 対象ウィンドウが存在しない（アプリ終了等）場合は非表示
- UWP アプリはフレームウィンドウを実体ウィンドウに読み替えて判定

## インストール

`obs-focus-filter.dll` を OBS のプラグインディレクトリに配置:

```
C:\Program Files\obs-studio\obs-plugins\64bit\obs-focus-filter.dll
C:\Program Files\obs-studio\data\obs-plugins\obs-focus-filter\locale\*.ini
```

## ビルド

[obs-plugintemplate](https://github.com/obsproject/obs-plugintemplate) ベース。

```
cmake --preset windows-x64
cmake --build --preset windows-x64
```

要件: CMake 3.28+ / Visual Studio 2022 以降（このリポジトリのプリセットは VS 2026 / Windows SDK 10.0.26100 を指定。環境に合わせて `CMakePresets.json` を調整）

## 対応環境

- Windows のみ（フォーカス判定が Win32 API 依存）
- OBS Studio 31 以降でビルド・動作確認
